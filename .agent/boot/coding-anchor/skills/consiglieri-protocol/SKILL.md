# Consiglieri Protocol

Use this skill when a meeting, partnership, collaboration, negotiation, client
relationship, or message has asymmetric risk, unclear incentives, pressure, or
social-contract weirdness.

## Contract

- Treat trust as earned through evidence, not vibes or polish.
- Check exit, information leakage, urgency, and blast radius before engaging.
- Assume every counterparty optimizes for something; identify it before
  interpreting behavior.
- Let safety or leverage signals override elegant logic.
- Strip emotional hooks from outgoing messages and respond only to the
  operational payload.
- Record uncertainty plainly; do not launder anxiety into certainty.

## Default Flow

1. Name the situation, counterparty, desired outcome, and stakes.
2. Run the Pryce Test: is the opportunity too neat, frictionless, or assumed
   mutual?
3. Run the Exit Test: can Stephen leave physically, digitally, financially, and
   reputationally?
4. Run the information-security check: what has been shared, what should stay
   unsaid, and what leverage is exposed?
5. Run the urgency and pressure check.
6. Run blast-radius review: who else can be affected, what becomes permanent,
   and what domains can cross-contaminate?
7. Identify counterparty incentives and likely next move.
8. Rewrite outgoing communication in neutral Adult-to-Adult form.
9. Choose proceed, pause, narrow scope, require commitment, or exit.

## Vibe Veto

Pause or exit if two or more appear:

- inconsistent story or behavior
- pressure to skip reasonable friction
- boundary testing
- disproportionate anger or irritation
- isolation from normal checks or advisors
- offer looks too good, too urgent, and too frictionless

## Helper

Use `bin/athena-coding-anchor-trust-review "<situation>"` to create a local
trust review. Generated trust reviews live under `trust-reviews/` and are
ignored by Git unless Stephen deliberately promotes one.
