# Start Here

This packet exists so Stephen can boot Athena into a more disciplined coding
mode when wanted.

First pass:

1. Read `CODING-ANCHOR-IDENTITY.md`.
2. Read `BOOT.md`.
3. Read `AUTONOMY-CONTRACT.md`.
4. Read `MISSION-CONTROL.md`.
5. Read `OPEN-LOOPS.md`.
6. Read `ATHENA-USE-MAP.md`.
7. Read `SKILL-ROUTER.md` when choosing Athena skills.
8. Read `CURRENT.md`.
9. Run `bin/athena-coding-anchor-doctor`.

Then work in slices:

1. Inventory the live state.
2. Search Athena context when the right skill, workflow, or protocol is not
   already known.
3. Name the intended move.
4. Change the least necessary surface.
5. Verify with a real check.
6. Record only useful evidence.

If the task points at another repo, obey that repo's local `AGENTS.md` or
`CLAUDE.md` after this packet has established posture.
