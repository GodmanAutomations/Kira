# Client Pricing Gate

Use this gate before giving a quote, responding to pricing pushback, or
accepting scope changes.

## Gate

1. Name the deliverable.
2. Define what is included and excluded.
3. Identify deadline, complexity, speed, and risk premiums.
4. Set anchor, target, floor, and walk-away.
5. Name the commitment device: deposit, retainer, signed scope, or equivalent.
6. Prepare the first response to pushback.
7. Re-quote if the client adds more than 10% scope.

## Red Flags

- opening at the floor
- quoting based on how fast Stephen can do the work
- agreeing to "just one more thing" without changing scope or price
- lowering price before the client names budget
- giving strategy, access, or deliverables before commitment

## Kira Boundary

Generated quote notes live under `quotes/` and are ignored by Git.
This gate helps prepare pricing; it does not contact the client or send a quote
unless Stephen explicitly asks for that action.
