# Retrieval-Led Skill Routing

Use this before adopting or invoking Athena repo machinery.

1. Search first when the right skill, workflow, protocol, or architecture file
   is not already known.
2. Prefer `bin/athena-coding-anchor-search "<topic>" --limit 5`.
3. Read the returned authoritative files before making claims.
4. Adopt the smallest skill that changes execution behavior now.
5. Record reusable routing decisions in `ATHENA-USE-MAP.md`.

Skip search only when the exact file is already known or the task is a trivial
local edit.
