# MCDA Decision Gate

Use this gate when a choice has multiple options, criteria, or stakeholders.

## Gate

1. Define the decision question.
2. List at least two real options.
3. Pick 3-7 criteria.
4. Assign weights that total 100%.
5. Score each option 1-10 per criterion.
6. Calculate weighted totals.
7. Check whether the winner changes if the highest-weight criterion moves by
   10%.
8. Check for veto/dealbreaker criteria before trusting the weighted score.

## Avoid

- fake options
- one criterion silently dominating the matrix
- false precision from arbitrary numbers
- hiding a gut/value conflict behind a spreadsheet-looking table

## Kira Boundary

Generated matrices live under `decision-matrices/` and are ignored by Git.
Use decision notes for final rationale when a choice needs durable review.
