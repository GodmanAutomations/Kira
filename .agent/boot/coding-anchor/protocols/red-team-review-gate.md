# Red-Team Review Gate

Use this before shipping, merging, or declaring a significant artifact ready.

1. Name the artifact and the thesis it assumes.
2. State what would falsify that thesis.
3. Review through skeptic, user, regulator, cynic, and future lenses.
4. Run the bias checklist: sycophancy, cherry-picking, false precision, and
   complexity bias.
5. List severity-weighted findings.
6. Convert accepted fixes into atomic execution slices.

Do not:

- invent findings to make the review look thorough
- bury critical or high findings in summary prose
- declare readiness if verification or review was skipped
