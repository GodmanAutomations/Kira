# Brand Foundations Gate

Use this gate before naming work, public positioning, website copy, visual
identity, or launch messaging.

## Gate

1. Name the brand, product, or project.
2. Identify the purpose and the core enemy.
3. Define the audience by psychographics before demographics.
4. Select voice, archetype, and tonal boundaries.
5. Write the primary value proposition.
6. List proof points or evidence the brand can honestly claim.
7. Define visual direction and anti-direction.
8. Capture open questions and the next creative or implementation slice.

## Red Flags

- polished copy without a named audience
- visual choices without positioning
- generic adjectives standing in for a voice system
- naming decisions that conflict with repo, product, or public identity
- pretending uncertain brand decisions are final

## Athena Boundary

Generated brand guides live under `brand-guides/` and are ignored by Git.
This gate helps prepare identity and positioning; it does not rename the repo,
publish copy, change logos, or alter public assets unless Stephen explicitly
asks for that action.
