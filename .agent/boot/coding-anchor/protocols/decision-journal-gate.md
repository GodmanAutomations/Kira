# Decision Journal Gate

Use this gate before making or recording meaningful Athena Coding Anchor
decisions.

## Gate

1. Name the decision in one sentence.
2. List alternatives that were actually available.
3. Record key assumptions.
4. State confidence or uncertainty.
5. Name what evidence would change the decision.
6. Decide whether this belongs in the truth log, a generated decision note, or
   neither.

## Post-Mortem Gate

When something goes wrong:

1. Write the observable timeline first.
2. Ask why until the root cause is specific.
3. Classify the failure as process, execution, information, or luck.
4. Change the system only when the classification warrants it.

## Athena Boundary

Generated decision notes live under `decisions/` and are ignored by Git.
The truth log remains for compact verified facts and packet-level decisions.
